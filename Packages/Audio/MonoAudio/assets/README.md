# MonoAudio logo assets

This directory contains SVG and transparent PNG versions of the mark and
horizontal lockup. The SVG files use solid fills and have no font, gradient, or
filter dependency.

| File | Use |
| --- | --- |
| `mono-audio-mark.svg` | Primary mark on light or neutral backgrounds |
| `mono-audio-mark-dark.svg` | Brighter mark on dark backgrounds |
| `mono-audio-mark-mono.svg` | One-color mark; inherits CSS `currentColor` |
| `mono-audio-lockup.svg` | Horizontal lockup on light backgrounds |
| `mono-audio-lockup-dark.svg` | Horizontal lockup on dark backgrounds |
| `mono-audio-mark.png` | 1024 px transparent raster export |
| `mono-audio-mark-dark.png` | 1024 px transparent raster export for dark backgrounds |
| `mono-audio-lockup.png` | 1720 × 320 transparent raster export |
| `mono-audio-lockup-dark.png` | 1720 × 320 transparent raster export for dark backgrounds |

Keep clear space equal to half the height of one stream. Do not add a container, recolor individual paths, distort the aspect ratio, or tighten the space between the mark and wordmark.

## 中文

本目录提供图标与横向组合标的 SVG、透明 PNG 文件。SVG 使用纯色填充，不依赖
字体、渐变或滤镜。

| 文件 | 用途 |
| --- | --- |
| `mono-audio-mark.svg` | 浅色或中性色背景上的主标 |
| `mono-audio-mark-dark.svg` | 深色背景上的高亮版本 |
| `mono-audio-mark-mono.svg` | 单色版本，继承 CSS `currentColor` |
| `mono-audio-lockup.svg` | 浅色背景横向组合标 |
| `mono-audio-lockup-dark.svg` | 深色背景横向组合标 |
| `mono-audio-mark.png` | 1024 px 透明位图导出 |
| `mono-audio-mark-dark.png` | 适合深色背景的 1024 px 透明位图导出 |
| `mono-audio-lockup.png` | 1720 × 320 透明位图导出 |
| `mono-audio-lockup-dark.png` | 适合深色背景的 1720 × 320 透明位图导出 |

安全留白至少为单条声路高度的一半。请勿添加外框、单独改变某一条声路的颜色、拉伸图形，或压缩图形与字标之间的间距。
